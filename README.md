### Nota de deprecação:
O sistema descrito aqui é o frontend react que seria carregado via github pages e leria dados estaticos de um segundo repositorio do github chamado `mithra-data`.

`mithra-data` serviria como um placeholder para um backend proprio, conteria scripts python utilitarios que leriam uma vault obsidian (provavelmente `mithra-geral`) e gerariam um payload `data.json` pronto para ser lido pelo frontend, o gestor então subiria o novo arquivo `data.json` para a branch main do github.

Este modelo front gh-pages e back com vault e data.json foi descontinuado e substituido por `MithraWebsis` que tenta incluir o manejamento de versões diretamente dentro do obsidian atravez de plugins. (Este MithraWebsis provavelmente será substituido em breve em nome de usar o plugin `atlas vtt` )

**os repositorios `mithra_webapp` e `mithra_data` estão todos deprecados e não são mais utilizados.**
